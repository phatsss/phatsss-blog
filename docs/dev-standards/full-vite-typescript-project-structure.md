# Vite + TanStack Project Setup

This guide will walk you through setting up a modern React project using Vite as the build tool and the TanStack libraries (Query, Router, Table, Form, etc.) for a complete frontend development experience.

## Prerequisites

- [Node.js](https://nodejs.org/en/download/) version 18.0 or above
- npm, yarn, or pnpm package manager

## Creating a Vite Project

First, let's create a new Vite project:

```bash
npm create vite@latest my-tanstack-app --template react-ts
```
