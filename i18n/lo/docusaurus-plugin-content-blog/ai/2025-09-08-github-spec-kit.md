ຄູ່ມືນີ້ຈະຊ່ວຍແນະນຳທ່ານກ່ຽວກັບການຕິດຕັ້ງແລະນຳໃຊ້ **GitHub Spec Kit** ຢູ່ໃນຄອມພິວເຕີ Mac ທີ່ໃຊ້ຊິບ **Apple silicon**. Spec Kit ແມ່ນເຄື່ອງມືສຳລັບວິທີການພັດທະນາແບບໃໝ່ທີ່ເອີ້ນວ່າ **Spec-Driven Development** (SDD), ເຊິ່ງທ່ານຈະນຳໃຊ້ AI agents ເພື່ອສ້າງລະຫັດໂປຣແກຣມຕາມຂໍ້ກຳນົດທີ່ຊັດເຈນ.

### ສິ່ງທີ່ຕ້ອງມີກ່ອນ

ກ່ອນທີ່ຈະເລີ່ມຕົ້ນ, ໃຫ້ແນ່ໃຈວ່າ Mac ທີ່ໃຊ້ Apple silicon ຂອງທ່ານມີສິ່ງຕໍ່ໄປນີ້:

-   **macOS**: macOS ເວີຊັນລ່າສຸດ.
-   **Git**: ຕ້ອງຕິດຕັ້ງແລະຕັ້ງຄ່າ Git ແລ້ວ. ທ່ານສາມາດກວດສອບໄດ້ໂດຍການພິມ `git --version` ໃນ Terminal ຂອງທ່ານ.
-   **Python 3.11+**
-   **uv**: ເປັນເຄື່ອງມືຕິດຕັ້ງແລະຈັດການຊຸດ Python ທີ່ວ່ອງໄວ.
-   **Coding Agent**: Spec Kit ສາມາດໃຊ້ງານໄດ້ກັບ AI coding agents ຕ່າງໆ ເຊັ່ນ: GitHub Copilot, Claude Code, ຫຼື Gemini CLI.

---

### ຂັ້ນຕອນທີ 1: ຕິດຕັ້ງ `uv` ແລະ Spec Kit

ກ່ອນອື່ນ, ທ່ານຕ້ອງຕິດຕັ້ງ `uv` ເຊິ່ງເປັນຂໍ້ກຳນົດເບື້ອງຕົ້ນຂອງ Spec Kit. ຈາກນັ້ນ, ໃຫ້ໃຊ້ `uv` ເພື່ອເລີ່ມຕົ້ນໂຄງການໃໝ່ດ້ວຍ Spec Kit.

ເປີດ **Terminal** ຂອງທ່ານແລະພິມຄຳສັ່ງຕໍ່ໄປນີ້:

1.  **ຕິດຕັ້ງ uv (ຖ້າທ່ານຍັງບໍ່ມີ):**
    ```bash
    curl -LsSf [https://astral.sh/uv/install.sh](https://astral.sh/uv/install.sh) | sh
    ```
2.  **ເລີ່ມຕົ້ນໂຄງການໃໝ່ດ້ວຍ Spec Kit:**
    ```bash
    uvx --from git+[https://github.com/github/spec-kit.git](https://github.com/github/spec-kit.git) specify init <PROJECT_NAME>
    ```
    ປ່ຽນ `<PROJECT_NAME>` ເປັນຊື່ໂຄງການຂອງທ່ານ. ຄຳສັ່ງນີ້ຈະສ້າງໂຄງສ້າງໂຄງການອັດຕະໂນມັດພ້ອມທັງແມ່ແບບທີ່ຈຳເປັນ.

### ຂັ້ນຕອນທີ 2: ສ້າງຂໍ້ກຳນົດ (`/specify`)

ຫຼັກການສຳຄັນຂອງ SDD ແມ່ນຂໍ້ກຳນົດ. ບ່ອນນີ້ແມ່ນບ່ອນທີ່ທ່ານອະທິບາຍສິ່ງທີ່ທ່ານຕ້ອງການສ້າງຢ່າງຊັດເຈນແລະລະອຽດ. ໃຊ້ຄຳສັ່ງ `/specify` ພ້ອມກັບ AI coding agent ຂອງທ່ານ (ຕົວຢ່າງ: ໃນ code editor ເຊັ່ນ VS Code ຫຼື chat interface ທີ່ຮອງຮັບ).

**ຕົວຢ່າງ:**
/specify ສ້າງແອັບພລິເຄຊັນເວັບແບບງ່າຍໆທີ່ຕິດຕາມນິໄສປະຈຳວັນຂອງຜູ້ໃຊ້ ເຊັ່ນ "ດື່ມນໍ້າ" ຫຼື "ອອກກຳລັງກາຍ". ມັນຄວນຈະອະນຸຍາດໃຫ້ຜູ້ໃຊ້ເພີ່ມນິໄສໃໝ່, ໝາຍວ່ານິໄສສຳເລັດແລ້ວໃນມື້ນັ້ນ, ແລະເບິ່ງປະຫວັດນິໄສທີ່ສຳເລັດ.

ຈາກນັ້ນ AI ຈະຖາມຄຳຖາມເພີ່ມເຕີມແລະສ້າງເອກະສານ `spec.md` ລະອຽດ, ເຊິ່ງຈະອະທິບາຍຄຸນສົມບັດແລະຄວາມຕ້ອງການຂອງໂຄງການ.

### ຂັ້ນຕອນທີ 3: ສ້າງແຜນການທາງດ້ານເທັກນິກ (`/plan`)

ເມື່ອຂໍ້ກຳນົດຊັດເຈນແລ້ວ, ທ່ານໃຊ້ຄຳສັ່ງ `/plan` ເພື່ອສ້າງແຜນການປະຕິບັດທາງດ້ານເທັກນິກ. ບ່ອນນີ້ແມ່ນບ່ອນທີ່ທ່ານໃຫ້ລາຍລະອຽດກ່ຽວກັບເທັກໂນໂລຢີແລະສະຖາປັດຕະຍະກຳ.

**ຕົວຢ່າງ:**
/plan ແອັບພລິເຄຊັນເວັບຈະມີ frontend ເປັນ React ແລະ backend ເປັນ Python ໂດຍໃຊ້ Flask. ພວກເຮົາຈະໃຊ້ຖານຂໍ້ມູນ SQLite ຢູ່ໃນເຄື່ອງສຳລັບການເກັບຂໍ້ມູນ.

AI ຈະນຳໃຊ້ຂໍ້ມູນຂອງທ່ານແລະຂໍ້ກຳນົດທີ່ມີຢູ່ແລ້ວເພື່ອສ້າງເອກະສານ `plan.md` ລະອຽດ, ເຊິ່ງລວມເຖິງຮູບແບບຂໍ້ມູນ, API endpoints, ແລະພາບລວມຂອງສະຖາປັດຕະຍະກຳ.

### ຂັ້ນຕອນທີ 4: ແຍກຍ່ອຍເປັນໜ້າວຽກ (`/tasks`)

ຂັ້ນຕອນຕໍ່ໄປແມ່ນການແຍກແຜນການອອກເປັນໜ້າວຽກນ້ອຍໆທີ່ສາມາດປະຕິບັດໄດ້. ໃຊ້ຄຳສັ່ງ `/tasks` ເພື່ອສ້າງລາຍການກວດສອບ (checklist) ຂອງສິ່ງທີ່ຕ້ອງເຮັດ.

**ຕົວຢ່າງ:**
/tasks

AI ຈະວິເຄາະເອກະສານ `plan.md` ແລະສ້າງເອກະສານ `tasks.md` ພ້ອມກັບລາຍການກວດສອບເຊັ່ນນີ້:

-   [ ] **ໜ້າວຽກ 1: ຕັ້ງຄ່າໂຄງສ້າງໂຄງການ** (ໂຟນເດີ frontend ແລະ backend)
-   [ ] **ໜ້າວຽກ 2: ປະຕິບັດ database schema** (ການຕັ້ງຄ່າແລະການຍ້າຍຖານຂໍ້ມູນ SQLite)
-   [ ] **ໜ້າວຽກ 3: ສ້າງ RESTful API endpoint ສຳລັບນິໄສ** (ສ້າງ, ອ່ານ, ອັບເດດ)
-   [ ] **ໜ້າວຽກ 4: ສ້າງ React component ສຳລັບ habit dashboard ຫຼັກ**
-   [ ] **ໜ້າວຽກ 5: ເພີ່ມໜ້າເບິ່ງປະຫວັດສຳລັບນິໄສທີ່ສຳເລັດແລ້ວ**
-   ...ແລະອື່ນໆ.

### ຂັ້ນຕອນທີ 5: ປະຕິບັດລະຫັດ (`/code`)

ເມື່ອໜ້າວຽກຖືກກຳນົດແລ້ວ, ທ່ານສາມາດໃຊ້ຄຳສັ່ງ `/code` ເພື່ອເລີ່ມຕົ້ນປະຕິບັດລະຫັດສຳລັບແຕ່ລະໜ້າວຽກ.

**ຕົວຢ່າງ:**
ສົມມຸດວ່າທ່ານຕ້ອງການປະຕິບັດໜ້າວຽກທີ 2. ທ່ານຈະໃຊ້ຄຳສັ່ງທີ່ຄ້າຍຄືກັບນີ້:
/code ປະຕິບັດ database schema ສຳລັບ habit tracker. schema ຄວນມີ habits table ພ້ອມດ້ວຍ id, name, ແລະ completed_at fields.

AI ຈະນຳໃຊ້ຂໍ້ກຳນົດ, ແຜນການ, ແລະຄຳອະທິບາຍໜ້າວຽກເພື່ອຂຽນລະຫັດທີ່ຈຳເປັນ ຫຼືໄຟລ໌ທັງໝົດໃຫ້ທ່ານ, ເຊິ່ງທ່ານສາມາດກວດສອບແລະ commit ໄດ້. ຂະບວນການນີ້ຈະຖືກເຮັດຊ້ຳສຳລັບແຕ່ລະໜ້າວຽກຈົນກວ່າໂຄງການຈະສຳເລັດ.
